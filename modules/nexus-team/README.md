# nexus-team – Überblick für das Community-Team

Eine Seite „Team“ in der oberen Navigation, nur für die Mitglieder einer HumHub-Gruppe (Einstellung `gruppe`, Vorgabe
„Community-Team“) und Systemadmins. Zeigt auf einen Blick:

- **Neue Mitglieder** der letzten 21 Tage: hat sich die Person im Vorstellungs-Kreis vorgestellt, hat Nova begrüßt, hat jemand
  vom Team begrüßt, wann zuletzt da (nur grob: heute / diese Woche / diesen Monat / länger). Mit Textvorschlag zum Begrüßen in
  der Sprache des Mitglieds (de, en, es, ru, fr), „Nachricht schreiben“ und „Habe begrüßt“.
- **Gemeldete Inhalte** (Modul reportcontent), **Beiträge ohne Antwort**, **Support-Anfragen**, **ruhige Kreise**.

Verändert keine Inhalte; die Moderationsrechte kommen von der HumHub-Gruppe (Berechtigung „Alle Inhalte verwalten“).
Bewusst keine Aktivitätszeiten und kein Verlauf.
