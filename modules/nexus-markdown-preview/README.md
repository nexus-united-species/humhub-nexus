# nexus-markdown-preview

🇩🇪 [Deutsch](#deutsch) · 🇬🇧 [English](#english)

## Deutsch

**Vorschau für `.md`-Dateien:** Neben hochgeladenen Markdown-Dateien erscheint ein Knopf „Vorschau“, der die Datei formatiert anzeigt (Überschriften, Listen, Fett/Kursiv, Tabellen) statt als Rohtext. Der Zugriff wird für jeden Aufruf serverseitig geprüft, das erzeugte HTML wird gereinigt (HtmlPurifier).

**Voraussetzungen:** HumHub 1.18+. **Einstellungen:** keine.

## English

**Preview for `.md` files:** next to uploaded Markdown files, a "Preview" button shows the file formatted (headings, lists, bold/italic, tables) instead of raw text. Access is checked server-side on every request, and the generated HTML is sanitised (HtmlPurifier).

**Requirements:** HumHub 1.18+. **Settings:** none.
