# nexus-notif-banner

🇩🇪 [Deutsch](#deutsch) · 🇬🇧 [English](#english)

## Deutsch

**Freundlicher Hinweis vor der Browser-Abfrage für Benachrichtigungen:** Statt sofort die nackte Systemabfrage („Benachrichtigungen erlauben?“) zu zeigen, die viele reflexartig blockieren, erklärt ein kleines Fenster zuerst, wozu die Benachrichtigungen gut sind. Erst nach „Ja“ kommt die Abfrage des Browsers. Berücksichtigt die Besonderheiten von iPhones (Abfrage nur als installierte Web-App).

**Voraussetzungen:** HumHub 1.18+ mit eingerichteten Push-Benachrichtigungen. **Einstellungen:** keine.

## English

**A friendly notice before the browser's notification prompt:** instead of immediately showing the bare system prompt ("Allow notifications?"), which many people block by reflex, a small window first explains what notifications are good for. The browser prompt only follows after "Yes". Handles iPhone specifics (prompt only available in the installed web app).

**Requirements:** HumHub 1.18+ with push notifications set up. **Settings:** none.
