# knowledge/

🇩🇪 Hier legst du die Dokumente ab, aus denen der Assistent sein Wissen über deine Gemeinschaft bezieht (z. B. Leitbild, Satzung, Handbuch, FAQ). Der Assistent liest Textdateien (`.md`, `.txt`) aus diesem Ordner und hängt sie an seine Anweisungen an. Fehlt eine Datei, wird sie übersprungen – der Assistent funktioniert auch ohne Wissensbasis.

Die Wissensbasis der N.E.X.U.S.-Community (Bauplan, Charta, Handbücher) ist **nicht** Teil dieses Repositories: Diese Texte sind urheberrechtlich geschützt.

Welche Dateinamen gelesen werden, steht in `services/WissensbasisService.php` (`VOLLTEXT_DATEIEN`, `AUSZUG_DATEIEN`) und `services/BauplanService.php`.

---

🇬🇧 Put the documents here from which the assistant draws its knowledge about your community (e.g. mission statement, bylaws, handbook, FAQ). The assistant reads text files (`.md`, `.txt`) from this folder and appends them to its instructions. Missing files are skipped – the assistant also works without a knowledge base.

The knowledge base of the N.E.X.U.S. community (blueprint, charter, handbooks) is **not** part of this repository: these texts are protected by copyright.

Which file names are read is defined in `services/WissensbasisService.php` (`VOLLTEXT_DATEIEN`, `AUSZUG_DATEIEN`) and `services/BauplanService.php`.
