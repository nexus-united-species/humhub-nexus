# nexus-themen

🇩🇪 [Deutsch](#deutsch) · 🇬🇧 [English](#english)

## Deutsch

**Themen wie bei Telegram:** HumHub kann Beiträge schon nach Themen (Topics) ordnen, aber die Funktion ist gut versteckt: Ein Thema wählt man beim Schreiben nur über das Zahnrad-Menü, gefiltert wird über ein Filtermenü. Dieses Modul macht beides sichtbar:

- **Themen-Leiste über dem Feed** jedes Kreises, der Themen hat: `Alle · 💬 Allgemein · …`. Ein Klick filtert den Feed (HumHubs eigener Themenfilter).
- **Auswahl „Thema“ beim Schreiben**, mit der Vorgabe „💬 Allgemein“. Ist der Feed gerade auf ein Thema gefiltert, ist dieses vorausgewählt.
- **„💬 Allgemein“** wird einmalig in jedem Kreis angelegt, sobald er Themen hat (heißt ein vorhandenes Thema schon „Allgemein“, wird es übernommen). Löschen die Kreis-Admins es, bleibt es gelöscht.

Themen anlegen, umbenennen und sortieren die Admins eines Kreises wie gewohnt in HumHub: Kreis → Zahnrad → Einstellungen → **Themen** (in der Leiste auch über ⚙). Mitglieder können keine neuen Themen anlegen (HumHub-Recht „Thema hinzufügen“), sie wählen nur aus. Das Thema eines vorhandenen Beitrags ändert man über „•••“ am Beitrag → Themen.

**Voraussetzungen:** HumHub 1.18+, Themen für Kreise erlaubt (Standard).

## English

**Topics like in Telegram:** HumHub can already sort posts by topics, but the feature is hidden: you pick a topic only via the cog menu of the post form, and filtering happens in a filter menu. This module makes both visible:

- **Topic bar above the stream** of every space that has topics: `All · 💬 General · …`. One click filters the stream (HumHub's own topic filter).
- **"Topic" choice when posting**, defaulting to "💬 Allgemein". If the stream is filtered to a topic, that topic is preselected.
- **The default topic** is created once in every space that has topics (an existing topic called "Allgemein" is reused). If space admins delete it, it stays deleted. Its name is the module setting `allgemeinName`.

Space admins create, rename and sort topics as usual in HumHub: space → cog → Settings → **Topics** (also via ⚙ in the bar). Members cannot create new topics (HumHub permission "Add topic"); they only choose.

**Requirements:** HumHub 1.18+, space topics allowed (default).
