# nexus-quicklinks

🇩🇪 [Deutsch](#deutsch) · 🇬🇧 [English](#english)

## Deutsch

**Links zu den anderen N.E.X.U.S.-Diensten** (Webseite, Cloud, Cockpit) in der oberen Navigationsleiste, jeweils in einem neuen Tab. Bewusst N.E.X.U.S.-spezifisch: Als Vorlage für eigene Links die Einträge in `Events.php` anpassen.

## English

**Links to the other N.E.X.U.S. services** (website, cloud, cockpit) in the top navigation bar, each opening in a new tab. Deliberately N.E.X.U.S.-specific: to use it as a template, adapt the entries in `Events.php`.
